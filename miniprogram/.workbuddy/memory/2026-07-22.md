# 2026-07-22

## 平衡车调参小程序 UI 全面升级（浅色科技风）

**触发**：用户反馈小程序"太丑了"，要求"在不改变小程序逻辑的情况下，尽可能优化UI设计、配色方案"。

**二次要求**：1) 不要暗黑系 2) 尽可能紧凑 3) 要有科技感，数值展示要炫酷。

### 改动文件
- `app.json` — 导航栏/状态栏/tabBar 改为白色/浅色，激活色 `#059669`
- `app.wxss` — page 底色 `#eef2f7`，文字 `#1e293b`
- `components/ble-status/ble-status.wxss` — 白色卡片 + 顶部三色渐变条 + 连接绿点脉冲
- `pages/index/index.wxml` — 仅修改三个 slider 的 `activeColor` / `backgroundColor`（纯视觉）
- `pages/index/index.wxss` — 浅色科技风：白色卡片+彩色左边框+渐变文字标题+紧凑布局
- `pages/control/control.wxml` — 重写空状态，添加遥控器装饰图标（纯装饰、无绑定）
- `pages/control/control.wxss` — 浅色遥控器图标 + 屏幕扫描动画
- `design-preview.html` — 设计预览图（浅色科技风）

### 设计方向（浅色科技风）
- **背景**：`#eef2f7` 浅灰蓝 + 三色径向光晕（绿/蓝/橙）
- **卡片**：纯白 `#ffffff` + `1rpx #e2e8f0` 边框 + 左侧 6rpx 彩色描边（Kp/Kd/Kv 各一色）
- **强调色**：Kp=翡翠 `#059669`、Kd=天蓝 `#0284c7`、Kv=琥珀 `#d97706`
- **字体**：等宽字体显示数字（SF Mono），标题用渐变色（`background-clip: text`）
- **紧凑**：padding 24rpx、margin 16rpx、字号全面收紧
- **科技感**：仪表盘顶部彩色指示条、等宽数字、渐变文字标题、数字显示框

### 重要原则
- **零逻辑改动**：所有 JS 文件未触碰；WXML 中数据绑定 `{{}}`、事件 `bindtap`、条件 `wx:if` 全部保留
- 仅改了 slider 的颜色字符串值（纯视觉属性），control 页加了纯装饰性 view 元素（无任何绑定/事件）
